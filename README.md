# interferenceAudit

Companies using individual level data may not know areas where there may be interference, and treatments applied at the individual level will have better gains when applied at cluster level. Given free text description of the output metrics, mechanisms we have to optimize these metrics, and company subscription plans, this agentic workflow will identify and rank the best possible prototypes to build. A human in the loop is still needed in order to verify the output, maintaining proper skepticism since AI will still suggest things that don't make sense either for a production system, or even methodologically. There is no Lean certification yet for whether something "makes sense in production."

Subsequently, a minimum viable product can then be built quickly with an agent.
